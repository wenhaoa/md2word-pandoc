# 转换流程

以[SKILL.md](../SKILL.md)为完整执行规则。

1. 根据用户给出的路径和上下文定位源文件，检查Pandoc、Node.js、Python和Python依赖。
2. 运行`node scripts/check_markdown.js 文件.md --json`，核对资源、题注、公式和引用。检查项是结构要求，不能据此改写技术内容。保留现有合理标题层级、明确编号引用和列表；不强制增加YAML。
3. 运行`node scripts/run_conversion.js 文件.md`。需要明确标题映射时用`--heading-mode shift`或`chapters`；参考文献上标仅在确认方括号数字为文献引用时使用`--citations`。
4. 所有必要后处理及结构检查通过后，输出独立docx。失败时查看保留的`.md2word-*`诊断目录，修复原因后重新运行；不得用跳过失败步骤的方式宣称完成。
5. 核对原文件未改动、输出可打开。Word中更新目录和域，检查封面、图片、分页、表格及公式位置；未实际检查版式时如实说明。

不凭图题相同删除题注，不把编号引用改成“如图所示”，不删除公式结构。
`--no-caption`只用于用户明确不需要题注及图表引用域化的导出。
返回输出路径和实际完成的检查，不把诊断文件当作正式交付文件。
